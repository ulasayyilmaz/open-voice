# Practice log

Record the same exercise and the same song phrase weekly and compare month to month.

## Baseline (Nov 2026)

- Nose breathing: free. Tonsils removed in childhood, so no structural blockage.
- Feels: throat often tense; voice throat-dominant.
- Discovery: with the head aligned against the wall, the voice turns strong, echoing and open (deep bass).
- Focus: alignment without the wall, throat release, daily SOVT.

## Daily routine (20–30 min)

| Block | Min | Exercises |
|---|---|---|
| Align & release | 3 | Wall alignment, jaw/neck release |
| Breath | 3 | Low wide inhale, "sss"/"zzz" |
| SOVT | 5 | Straw or lip trills: sirens, 5-note scales |
| Resonance | 5 | ng→ah, mm-ah |
| Space & release | 4 | Yawn-onset inhale, tongue-out "ah", silent laugh |
| Apply | 5–10 | One phrase: trill → ng → vowels → words |
